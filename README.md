# 性格で変わる物語

登場人物の性格（ビッグファイブ5因子×3段階）を決めると、お話の流れと結末が変わる絵本劇のサイト。

- `index.html` トップ。お話の一覧は `stories.json`（お話を足すときはここに1件足す）
- `three-pigs/` 三びきのこぶた：性格を選ぶページ
- `three-pigs/play/` 3Dの劇（制作元から `tools/build_player.py` で組み立てる。手で直さない）
  - 25MBを超えるGLBは `.partN` に分割し、`<名前>.parts.json` からつなぎ直して読む
- 性格の番号は5けた（開放性・誠実性・外向性・協調性・感受性の順、1＝低い・3＝ふつう・5＝高い）。ビッグファイブ診断の結果番号と同じ並び
